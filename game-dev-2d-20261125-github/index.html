2今日のゴール

「1周」の定義

1周 = この4つがつながっていること
  • タイトル画面から始められる
  • 遊び方・操作が分かる
  • 遊んで、終わり（クリア／ゲームオーバー／結果）まで行ける
  • もう一度遊べる（リトライ）
通っていないチームへ

新機能を足すのは今日は止める。まず通すこと。範囲を切る判断も、今日ここで決めること。

6金曜の提出

金曜（11/27）通し動画の提出仕様

撮るもの
  • タイトルから始めて、1周（結果が出るまで）を通して撮る
  • 編集でごまかさない。詰まったら詰まったまま（それも評価材料）
  • 長さの目安は1〜3分
評価について

金曜はゲーム自体の完成度を評価します。push数ではありません。「1周通っているか」「遊び方が伝わるか」「終わりまであるか」が中心です。
