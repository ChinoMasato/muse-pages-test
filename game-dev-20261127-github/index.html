04肉付けループとは

「直す→push→遊ぶ→決める」を回し続ける

肉付けループは、ゲームに中身（肉）を足していく進め方。大きな作業を一気にやらず、小さな周回を何度も回して太らせていく。今日の授業の本体はこれ。

  1. 直す（小さく1つ） ― 直すのは1つだけ。同時に2つ直すと、壊れたとき原因が分からなくなる
  2. push（その場で） ― 直したら、まとめて後ではなく、その場でpushする。pushが「1周した」記録になる
  3. 遊ぶ（チーム内で） ― 作った本人ではなく、チームの別の人が遊ぶ。詰まった所・分からなかった所が、次の材料になる
  4. 決める（次の1つ） ― 遊んで分かった一番の詰まりを、次の「直す1つ」にする。ここから2周目
なぜ小さく回すのか

小さく直せば、壊れても原因がすぐ分かる。「完成してから遊ぶ」ではなく「遊びながら完成させる」のが、このループの考え方。

今日の勝負

1限〜2限前半で、何周回せるか。最後の動画は、このループで太らせた結果を撮るもの。周回数が、そのまま動画の中身になる。

09撮影の仕様

撮り方 ― ルールは4つ

撮影は授業の最後。撮り方はこのルールだけ守る。

撮るもの
  • タイトルから始めて、1周（結果が出るまで）を通して撮る
  • 長さの目安は1〜3分
  • 撮影の直前に、最新の状態をpushしておく（動画とリポジトリの状態を一致させる）
ごまかさない
  • 編集でつないで「通ったこと」にしない
  • 詰まったら、詰まったまま撮る。それも評価材料になる
  • 音が出るゲームは、録画にも音が入る設定で撮る
通らない所を隠した動画より、通らない所が見える動画の方が、次の直しにつながる。
10撮影前チェック

最後の撮影の前に、この6点だけ確認する

撮影の直前にこの表で確認してから撮る。

  • 最新の状態をpushした（動画に撮る状態 ＝ リポジトリの状態）
  • タイトル画面から始められる
  • 遊び方・操作が、画面から読み取れる
  • 終わり（クリア／ゲームオーバー／結果）まで行ける
  • もう一度遊べる（リトライできる）
  • 録画に音が入っている（音のあるゲーム）

1つでも欠けていたら、それがループで次に直す「1つ」。撮影直前なら、直せる範囲で1つだけ。優先順位は「終わりまであるか」が最優先。
