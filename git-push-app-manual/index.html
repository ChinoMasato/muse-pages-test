GitHub リポジトリ登録アプリ｜使い方

このアプリは、自分のゲームをGitHubに上げる作業を、ボタン1つで終わらせるためのものです。リポジトリの作成、登録（init）、コミット、push、pullまで全部自動でやります。コマンドを打つ必要はありません。

画面はこんな形です

GitHub リポジトリ登録アプリ
D:\自分のゲームのフォルダ　［選ぶ...］

my-game-project　　☑ GitHubに自動で作る　☑ 非公開にする
（空でOK）
（空でOK）
commit して GitHub へ push
GitHubのページを開く: https://github.com/あなた/リポジトリ名
=== 開始 ...
=== 成功: GitHubに上がりました。

初回の手順（4ステップ）

1アプリを開く

配られた GitPushApp.exe をダブルクリックします。青い警告画面（「WindowsによってPCが保護されました」）が出たら、「詳細情報」→「実行」の順に押してください。これは配布元が未登録のアプリを開くときの、Windowsの通常の確認です。

2フォルダを選ぶ

「選ぶ...」から、自分のゲームのプロジェクトフォルダを選んでください（Unityなら、Assetsフォルダが入っている場所です）。フォルダは記憶されるので、次回からは選ぶ必要がありません。

3リポジトリ名を確認する

名前はフォルダ名から自動で入ります。フォルダ名が日本語だと名前が空になることがあるので、その場合は英数字で入れてください（例：mamono-gourmet-rpg）。「GitHubに自動で作る」と「非公開にする」のチェックは、入れたままでOKです。

4ボタンを押す

「commit して GitHub へ push」を押します。途中でGitHubのサインイン画面が出たら、自分のGitHubアカウントでサインインしてください。終わったら、青いリンク「GitHubのページを開く」から、自分のページにファイルが上がっていることを確認してください。

リポジトリは非公開で作られ、先生（chinomasato）が自動で招待されます。先生からは見えるので、そのまま提出になります。

2回目以降（毎日のpush）

ボタンを押すだけ

アプリを開いて、ボタンを1回押すだけです。フォルダは記憶されています。流れは pull（GitHub側の変更を取り込む）→ commit → push で、コミットメッセージも空欄なら日時で自動入力されます。自宅と学校の両方で作業している人は、先に取り込んでから上がるので、ぶつかりにくくなります。

止まったときは

「100MBを超えるファイル」で止まった

GitHubには1ファイル100MBまでしか上げられません。表示されたファイルを確認してください。Unityの「Library」フォルダのファイルなら、「Unityプロジェクト」のチェックが入っているか確認してください。大きな動画や音源ファイルは、プロジェクトの外に出してから、もう一度押してください。

ロックファイルの確認が出た

Museなど、別のプログラムがgitを使っているときに残ることがあります。そのプログラムを使い終わっているなら「はい」（削除して続行）で大丈夫です。使っている最中なら「いいえ」を選んで、終わってからもう一度ボタンを押してください。

「競合」で止まった／よく分からないエラーが出た

自分のコミットは消えていません（安全な状態で止まっています）。アプリの下のほうに出ているログの文面を、そのまま先生に見せてください。自分で直そうとしてファイルを消したりしないでください。

知っておくこと

  • 名前とメール（コミット用）は、GitHubアカウントから自動で設定されます。メールにはGitHubの匿名アドレスが使われるので、本物のメールアドレスが公開されることはありません。
  • このアプリがパスワードを聞くことはありません。サインインは、GitHub公式の画面でのみ行ってください。
  • 「Library」などの自動生成フォルダは、最初から上がらない設定になります。消してもUnityが作り直すので心配いりません。

分からないことがあれば、ログの文面と一緒に千野まで連絡してください。
