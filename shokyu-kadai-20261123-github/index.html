02なぜGitHubに上げるのか

一番大きいのは、自分のAIエージェントとコードを共有できること。

GitHubに上げると、自分のAIエージェントにリポジトリを読ませて、そのまま一緒に開発できる。コードを貼り直したり、状況を言葉で説明し直したりしなくても、AIエージェントが今のコードを読んだ状態で作業が始まる。AI駆動開発のフローが、ここでつながる。

⭐ 最大のメリット ─ 自分のAIエージェントとつながる
  • 自分のAIエージェントがリポジトリ全体を読んで、今のコードを前提に直す・足す・調べる
  • 「作る → 上げる → AIエージェントに読ませて直す → また上げる」のAI駆動開発のループが回り始める
  • 手元だけで開発していると、このループはつながらない。上げることが、その入口になる
🛠 先生のMuseからも見てもらえる
  • chinomasatoを登録すると、先生のMuse（AIエージェント）もリポジトリを読んで開発状況を把握できる
  • 開発のサポートも、ポートフォリオ作りのサポートもシームレスになる
📁 ポートフォリオの材料になる
  • 作ったものと作る過程が、そのままポートフォリオの材料になる
  • 就活で見せる「作品」と「過程」が、リポジトリ1つに揃う
まず自分のためだ。上げた瞬間から、自分のAIエージェントと一緒に開発できる状態になる。 ▶ 03 記録が残る
上げる理由の一番は、自分のAIエージェントとコードを共有でき、AI駆動開発のフローがつながること。先生のClaudeが見られること、ポートフォリオはその次。
03記録が残る、ということ

試行錯誤まで残るから、アピールに漏れがない。

GitHubに上げ続けると、コミット（変更の記録）として、開発の過程そのものが残る。完成品だけではなく、何を試して、何に詰まって、どう直したかまで、後からたどれる。

全部
コミットに残る
✅ 記録があると
  • 「何をアピールすればいいか」を、AIと一緒に履歴から拾える
  • 工夫した点・苦労した点が、記憶頼みにならず証拠として残る
  • ポートフォリオや面接で、過程まで含めて語れる
⚠ 記録がないと
  • 完成品しか残らず、過程の工夫は自分でも思い出せなくなる
  • アピールポイントの漏れが出る（やったのに、言い忘れる）
  • AIも過程を見られないので、支援が的外れになりやすい
大事なのは結果だけじゃない。試行錯誤まで含めて、すべてが記録に残り、AIで把握できることだ。
コミットに試行錯誤まで残るので、アピールポイントの漏れがなくなる。
04AIとの付き合い方

全部をAIにゆだねなくてよい。

GitHubに上げるのは、全部をAIに任せるためではない。任せるところは任せて、自分でやるところは自分でやる。その線引きは自分で決めていい。

🤖 任せてよいところ
  • エラーの原因調べや、直し方の相談
  • 繰り返しの作業や、定型的なコードのたたき台
  • 記録の整理や、ポートフォリオの材料の拾い出し
✋ 自分でやるところ
  • 「どんなゲームにするか」の判断と決定
  • 遊んでみて面白いかどうかを確かめること
  • 最終的に何を提出し、何をアピールするかの選択
重要なのは、AIに任せる範囲ではない。開発の記録を、AIが把握できる状態にしておくことだ。記録さえつながっていれば、任せる・任せないをその都度選べる。
全部をAIにゆだねなくてよい。重要なのは開発記録をAIが把握できること。
05手順1 ─ リポジトリを作って上げる

作って、最新版を上げて、目で確認する。

📮 手順
  1. GitHubで新しいリポジトリを作成する（名前は作品が分かるものに。例：作品名や「2D個人制作」など）
  2. 今作っている個人制作のプロジェクトを、そのまま上げる
  3. 手元の最新版を上げる（古い版や、一部だけのファイルはNG）
  4. 上げ終わったら、ブラウザでリポジトリを開いてファイルが揃っているか目で確認する
詰まったら、止まったままにしない。エラー文をそのまま控えて、早めに先生に声をかける。 ▶ Museへの頼み方
💬 Museに頼むとき（コピペ用）
「GitHubに個人制作のリポジトリを作って、プロジェクトを上げたいです。手順を1つずつ教えてください。エラーが出たら、その都度貼るので原因を教えてください」

06手順2 ─ メンバー登録とURL共有

chinomasatoを登録して、URLを共有する。

👥 メンバー登録の手順
  1. リポジトリの Settings を開く
  2. Collaborators（コラボレーター）を開く
  3. chinomasato を検索して追加（招待）する
  4. メンバー一覧に chinomasato が表示されることを目で確認する

登録できたら、リポジトリのURLをコピーして、授業で案内された共有先に投稿する。
